# 🏙️ SmartCity Web Application

A responsive SmartCity web application designed to provide citizens with easy access to city services, complaint management, emergency services, announcements, and city monitoring features.

## 🚀 Features

- 🏠 Responsive SmartCity homepage
- 🏛️ City services and online service requests
- 📝 Report civic issues and complaints
- 📷 Upload photos when reporting an issue
- 🆔 Automatic complaint ID generation
- 🔍 Track complaint status
- 📋 View and filter complaints
- 📊 Complaint status timeline
- 🗺️ City monitoring dashboard
- 🚨 Emergency services
- 📢 City announcements
- 👨‍💼 Admin dashboard
- 🔄 Update and manage complaint status
- 🗑️ Delete complaints with confirmation
- 💾 Client-side data persistence using localStorage
- 📱 Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- LocalStorage

## 💡 Project Highlights

This project demonstrates a frontend-based SmartCity platform where citizens can interact with different municipal services and manage civic complaints.

The application uses browser localStorage for client-side persistence and mock data instead of a backend database or paid APIs.
